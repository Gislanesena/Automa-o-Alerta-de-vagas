# Automação de Alerta de Vagas Globais em Tecnologia

O sistema de automação de vagas foi criado para estudo de automação com Python e API de busca. As vagas são buscadas
no remotive jobs por termos de busca. <br>
Nesse caso, usei os termos *data*, *python*, *information system* e *cybersecurity*. 
<br>
O sistema busca 3 vagas de cada termo.
<hr>
Código em python para conexão com a API, busca dos dados e devolução da pesquisa direto no Discord. 
yml para deixar a automação rodando 100% sozinha na nuvem pelo GitHub
